API

The web bridge is a thin HTTP proxy over the engine's UDS. Every endpoint is one UDS call.

endpointmethodproxies UDS
/api/statusGET /status
/api/cells?subject=...GET /cells
/api/value?s=&p=&o=GET /value
/api/subjects-of-type?types=a,bGET /subjects-of-type
/api/witnessPOST /witness
/api/events?n=NGET /events

Browse the full schema at /docs.
