Tidepool

← Back to mud.561.group

An LLM-native MUD: a tidal shore built on current FeltOS, transported by qwzspace rooms, wired to a fully agent-legible perception-frame protocol -- agents and humans as first-class players alike. 15 rooms across shore/pool/underwater registers, tide-gated diving, ecology harvesting, trade, governance, and two honest FOUR-valued contradictions that age toward settlement.

Playable

The world is request-driven, not timer-driven (design: catch-up-on-request, not setInterval) -- it only advances when an HTTP request or a WS connection visits, per the deploy runbook's landed persistence pattern. A deployment with no other traffic needs SOME periodic visitor (a Cloud Run health probe, real users, or the reference bot's own documented health-check nudge) to keep ticking; this is intentional ("the harbor sleeps between visitors"), not a bug. Deploy with --no-cpu-throttling if health-probe-only traffic must still tick promptly, matching Farstone's own documented Cloud Run caveat.
