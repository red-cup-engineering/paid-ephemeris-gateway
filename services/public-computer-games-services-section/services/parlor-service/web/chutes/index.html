No wagering, nothing to win or lose but bragging rights. Pure chance — this game has no decisions in it at all.

Start a race

1-4 players, any mix of "You" and "Bot." A bot makes exactly the same move a human does when it's their turn — roll the die, move the piece — because there is nothing else to decide. The bot is a die with a seating position, not an opponent.

This button does the exact same thing on every turn, whether it's "You" or a "Bot" rolling — there is no code path anywhere in this game that treats a bot's turn any differently from a human's. That sameness is the game.
