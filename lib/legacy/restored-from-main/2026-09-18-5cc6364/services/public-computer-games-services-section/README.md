# Public Computer Games Services Section

This is Cowrie Games, packaged as `@causeway-services/cowrie-games` — the Causeway Services games label, described in its own `package.json` as "the public shelf of 561 games, free-to-play, earn-only, kind by executable test." Its children are individual game services: `solitaire-service`, `durante-services-section`, `stoke-service`, `gambling-trainer-service`, `equivo-service`, `vaultmaze-service`, `parlor-service`, `okaga-services-section`, `ruinfold-services-section`, `flickering-delve-service`, `onestone-service`, `crucible-service`, `fyreside-services-section`, and `you-are-conscious-service`. Public web games, including Be Not So Fearful, live in `public-web-games-services-section/sites/`.

The games section operates [play.561.group](services/public-web-games-services-section/sites/play.561.group/README.md), alongside the individual game sites in that carrier.
