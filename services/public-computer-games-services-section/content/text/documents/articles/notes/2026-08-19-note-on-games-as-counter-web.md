# Games as Counter-Web

The Jiangshi Web paper describes the semantic web as animation without spirit: crisp
global typing meant to eliminate ambiguity, which instead produces brittle clarity — a
web that can hop but not dance. Its prescription is soft schemas, defeasible semantics,
local vocabularies, reversible commitments, and conflicts treated as information rather
than errors.

The games fleet already does most of this, without ever having been built as a web
architecture:

- **Four-valued evidence logic instead of crisp typing.** The bilattice used across the
  fleet holds "both true and false" as a real situation, not an error state — a permit
  going overdue-and-valid at once is defeasible semantics running in production.
- **Conflicts as information.** The paraconsistent trace is exactly that: contradictions
  are recorded and reasoned about, not raised as exceptions.
- **Local semantics.** Every game keeps its own registers and vocabulary, connected by
  explicit, documented ports rather than forced onto one global schema.
- **Reversible commitments.** Settling is computed fresh each time as a fixpoint, never
  stored as a final declaration.

A game is the one kind of web artifact whose joints have to flex — play only works if
there is real surprise and real doubt. That is the strategic reading: the shelf is the
soft-jointed web wearing a friendly face, and each game is a small proof that ambiguity
can be computed with instead of eliminated away.

The same lens turns inward usefully. Compiling the house's own design notes as a vault
(see the VaultMaze note) surfaced 39 rooms connected by only 3 doors — files that share
tags but almost never cite each other. That is a vault with frozen joints: taxonomy
without argument. A door-count-to-room-count ratio is worth tracking as a cheap, already-
computed health number for the notes corpus itself.

## What the fleet sells: witnessed play

The house's trade doctrine holds that in an economy where anyone can generate content,
the scarce good is the witness — every product is a form of verification sold at a
boundary. Read through that lens, the games fleet's replay-verification machinery (built
originally for anti-cheat) is the product itself:

1. **To players: trust.** Computed-not-asserted odds, published RTP, payouts bounded by
   verified revenue, kindness enforced by executable tests. A game whose numbers are
   provably true is a different thing from most of what's on the web today.
2. **To advertisers: verified human attention.** A replay-verified play session is a
   witness that a real human (or a declared agent peer — the fleet distinguishes the two
   honestly) spent real attention. Proof-of-play functions as proof-of-attention with a
   signed verdict, priced across a boundary the house cannot fake without breaking its
   own hashes.
3. **To other studios, eventually: verification as a service.** The cartridge verifier
   could be offered as a product boundary in its own right. This is unbuilt — named here
   as a direction, not a commitment.

A useful discipline for any shelf product: name its outside wallet and a quarter of real
revenue against it, or admit it is unrealized research rather than a shipping product.
That keeps "real profit" real — the fleet is a set of small enterprises, each facing an
actual wallet test, not a portfolio of demos.

## Where this sits in the larger structure

The house's dependency chain runs from foundational knowledge through formalization,
language systems, and a Rendanheyi-style corporation, out to public web services. Games
are the web-services rung — the first thing a stranger touches. Concretely: the fleet
generates independent revenue routed toward a sovereignty-directed enterprise, campaigns
like the Seasonal Round carry real scholarship into a mass genre, and the catalog
demonstrates that the house's underlying mathematics ships consumer products. Games with
no connection to any of that — pure clones with no witness thesis, no scholarship, no
revenue — sit outside the fleet's actual scope.

The one-person-plus-agent-fleet shape gets its economic logic from the same doctrine:
the marginal cost of *building* collapsed, so design judgment is the scarce input — but
the marginal cost of *witnessing* also collapsed, since determinism makes verification
nearly free, while the market price of a genuine witness rises as generation gets
cheaper everywhere else. The fleet is structurally long the one good whose price the
current era is raising.
