# Okaga

Okaga is an Elite-like space-flight game: a galaxy to fly through, a trade economy, and ship management, built on tsander, the house's wireframe-3D engine. Its own README frames it explicitly as "a game, not just a setting."

## A separate vision item shares this name

`2026-08-19-note-on-gaming-enterprises-vision.md` §4 names "Okaga-setting games" as a distinct, later-stage idea: future games set in the Okaga fictional universe, chosen because the underlying mathematics of the setting fits it. The concept is built around a credits-as-warp economic conceit — money equals energy equals time, so purchasing credits is what enables warp travel or other setting-native effects, skinning the shared energy-ledger mechanic used elsewhere in the house's games. No specific new game is named for this vision item. It is not a request to rebuild the space-flight game described above; it's an open invitation for future, unwritten games in the same fictional universe. The space-flight game is a completed, playable-when-recovered artifact from a specific setting; the vision item is a separate, open-ended idea that happens to share a name.
