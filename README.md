# Public Computer Services Section

This section holds the 561 Group's public-facing computer work.
`public-web-services-section` covers web1/web2/web3, web divination, web software development, and web games.
`public-computer-games-services-section` is Cowrie Games — the Causeway Services games label, described in its own `package.json` as "the public shelf of 561 games, free-to-play, earn-only, kind by executable test" — and holds a dozen-plus individual game services (solitaire, be-not-so-fearful, durante, stoke, and others).
`public-blockchain-services-section` holds public blockchain work, currently one child, `blockchain-trashpanda-services-section`.

public-computer-data-services-section holds Causeway Services' public computer data face.
