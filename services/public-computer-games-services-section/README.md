# Public Computer Games Services Section

This is Cowrie Games, packaged as `@causeway-services/cowrie-games` — the Causeway Services games label, described in its own `package.json` as "the public shelf of 561 games, free-to-play, earn-only, kind by executable test." Its children are individual game services: `solitaire-service`, `be-not-so-fearful-service`, `durante-services-section`, `stoke-service`, `gambling-trainer-service`, `equivo-service`, `vaultmaze-service`, `parlor-service`, `okaga-services-section`, `ruinfold-services-section`, `flickering-delve-service`, `onestone-service`, `crucible-service`, `fyreside-services-section`, and `you-are-conscious-service`.

Public publishing operates the [play.561.group](../../../public-publishing-services-section/services/public-computer-publishing-services-section/services/public-system-computer-publishing-section/services/public-web-publishing-services-section/sites/play.561.group/README.md), [mud.561.group](../../../public-publishing-services-section/services/public-computer-publishing-services-section/services/public-system-computer-publishing-section/services/public-web-publishing-services-section/sites/mud.561.group/README.md), and [Cloudflare router](../../../public-publishing-services-section/services/public-computer-publishing-services-section/services/public-system-computer-publishing-section/services/public-web-publishing-services-section/sites/cloudflare-router/README.md) carriers.
