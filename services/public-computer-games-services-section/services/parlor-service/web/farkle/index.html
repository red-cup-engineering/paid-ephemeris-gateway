    Rules

    Roll the dice pool, set aside any valid scoring group (a 1, a 5, or three-or-more of a kind), then roll the rest or bank. Set aside every die and the pool refills to six — "hot dice" — without losing your turn points. A roll that scores nothing busts the whole turn. Reach 500 points in one turn to get on the board; first to 10000 wins. bot takes the maximal scoring set every roll and plays the exact EV sign shown above.

    Keyboard

    1–6 toggle a die on the table · A set aside selection · R roll · B bank · T today's game · N new random game. Every die and control is also a plain focusable button.

    Rules and odds computed live by @red-cup-engineering/parlor-kernel. Determinism: the same seed always deals the same dice.
